# Supplement S1 — Exact two-door calculation

This supplement accompanies the hypothetical inspection example in
“Asymmetric Relations Between Needs and Data Availability in Predictive
Maintenance Systems.” It contains no empirical station data.

The archive `two-door-calculation.zip` contains:

- `calculate.py`: the deterministic Python calculation;
- `parameters.json`: the exact hypothetical inputs;
- `results.json`: exact gains, dominance comparisons, both selection criteria,
  ties, continuous bounds, and the separately identified historical rule;
- `plot_data.json`: drawing geometry generated by the calculation;
- `two_door_results.tex`: the generated manuscript table;
- `README.md`: these instructions.

All numbers in the inputs are strings interpreted as rational numbers.
Minimax regret and maximin incremental gain operate on undominated policies.
The comparison does not assign probabilities to the routing models and does
not impose a constraint of nonnegative gain in every model. The manuscript
explains those objectives and their different recommendations.

## Regeneration

Extract the archive into a directory and run the following there with
Python 3.10 or later. Only the standard library is needed; no packages or
random seed are required. Explicit output paths keep the archived reference
files intact.

```sh
python3 calculate.py --config parameters.json --json-output regenerated/results.json --tex-output regenerated/two_door_results.tex --plot-output regenerated/plot_data.json
```

Compare the regenerated files with the supplied reference files:

```sh
python3 - <<'PY'
from pathlib import Path
for name in ('results.json', 'two_door_results.tex', 'plot_data.json'):
    assert Path(name).read_bytes() == (Path('regenerated') / name).read_bytes(), name
    print(name + ': identical')
PY
```

The script includes no timestamps or machine-specific paths in its generated
outputs. The figure uses `plot_data.json`; drawing the figure is separate from
the exact calculation and is not required to verify the table or boundaries.

## Interpretation

The default comparison varies routing models at each fixed coefficient and
inspection sensitivity. The whole-rectangle stress comparison uses a different
uncertainty set. The rectangle is a hypothetical sensitivity domain, not an
elicited probability distribution. Response benefits and inspection burdens
use arbitrary loss units. Actionable-condition probabilities are not physical
failure probabilities, and sensitivity ranges are not empirical estimates.

The supplement is prepared locally for author review. No public deposit or
submission is asserted by these files.

# Diagram preview environment

This optional uv project declares the Python tools used by the shared renderer
at `../../scripts/render_tikz.py`. It is separate from manuscript compilation;
LaTeX can compile the inline diagram sources without this Python environment.
The renderer also requires a system LaTeX installation with TikZ, `standalone`,
and Palatino (`mathpazo`).

The declarations record the versions observed during the 2026-10-19 preview
checks: Python 3.12.7, PyMuPDF 1.27.2.3, PyYAML 6.0.1, and pytest 9.0.3.
`uv.lock` was generated by uv using static package metadata and the existing
interpreter. No packages or interpreters were installed or changed.

To create or synchronize the optional environment yourself, run from the
repository root:

```sh
uv sync --project tools/diagrams --locked
uv run --project tools/diagrams --locked python scripts/render_tikz.py --strict paper
uv run --project tools/diagrams --locked python scripts/render_tikz.py --verify paper
uv run --project tools/diagrams --locked python -m pytest -q tests/test_tikz_pipeline.py
```

For an existing compatible interpreter, directly invoke that interpreter to
avoid changing its environment. The preview checks used
`/opt/anaconda3/bin/python` locally; that absolute path is not a project
requirement.

The environment-management checker passed the two production requirements and
the Python range/exact-version checks. It skips development groups; pytest's
installed distribution was checked separately. An offline
`uv lock --check --no-python-downloads --no-build` check passed using cached
metadata. These checks do not verify that the existing interpreter has every
transitive version recorded in `uv.lock`.
